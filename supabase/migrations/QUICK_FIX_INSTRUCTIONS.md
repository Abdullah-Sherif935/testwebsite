# ⚡ حل سريع: خطأ "permission denied for table users"

## المشكلة
عند محاولة تقديم طلب توثيق، يظهر خطأ: **"permission denied for table users"**

## السبب
سياسات RLS الحالية تستخدم `auth.users` بشكل خاطئ، مما يسبب خطأ في الصلاحيات.

## ✅ الحل الكامل

### الخطوة الوحيدة:
1. افتح **Supabase Dashboard**
2. اذهب إلى **SQL Editor**
3. انسخ والصق محتوى الملف: **`20260121_COMPLETE_FIX_RLS.sql`**
4. اضغط **Run**
5. ارجع للموقع واعمل **Refresh** وجرب مرة أخرى

---

## 📋 ما سيفعله الكود

### سيحذف السياسات القديمة الخاطئة:
```sql
❌ SELECT email FROM auth.users WHERE id = auth.uid()
```

### سيضيف سياسات جديدة صحيحة:
```sql
✅ auth.jwt() ->> 'email'
```
